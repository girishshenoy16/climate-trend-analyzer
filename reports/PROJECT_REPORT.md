# Scientific & Technical Project Report

## Climate Trend Analyzer

### Executive Summary

The Climate Trend Analyzer is a comprehensive data engineering system designed to perform end-to-end climate analysis, predictive forecasting, and executive reporting for urban climate monitoring. The system processes multi-decadal climate data from public APIs, applies machine learning techniques for anomaly detection, generates time-series forecasts, and produces executive-ready reports with actionable climate risk assessments.

## 1. Introduction

### 1.1 Problem Statement

Climate change presents significant challenges for urban planning, public health, and infrastructure management. Understanding long-term climate trends, detecting anomalies, and projecting future conditions requires sophisticated data analysis capabilities that are often inaccessible to non-specialists.

### 1.2 Objectives

- Build a modular, reproducible climate analysis pipeline
- Integrate multiple public climate data sources
- Apply machine learning for anomaly detection
- Generate actionable climate risk assessments
- Deploy results via dual web platforms (static + interactive)

## 2. Data Sources

### 2.1 NASA POWER API
- **Parameters:** Temperature (T2M, T2M_MAX, T2M_MIN), Precipitation (PRECTOTCORR), Humidity (RH2M), Solar Radiation (ALLSKY_SFC_SW_DWN), Wind Speed (WS2M)
- **Resolution:** Daily
- **Coverage:** Global, 1981-present

### 2.2 Open-Meteo Climate Archive API
- **Parameters:** Temperature, Precipitation, Humidity, Solar Radiation, Wind Speed
- **Resolution:** Daily
- **Coverage:** Global, historical archive

### 2.3 Data Merging Strategy
Open-Meteo serves as primary source with NASA POWER as fallback for missing values, ensuring maximum data completeness.

## 3. Methodology

### 3.1 Data Processing Pipeline
1. **Acquisition:** Dual API fetch with HTTP caching and retry logic
2. **Validation:** Schema enforcement, date bounds checking, type conversion
3. **Imputation:** Linear interpolation for missing values
4. **Feature Engineering:** Temporal features, rolling averages, lag features

### 3.2 Exploratory Data Analysis
- Summary statistics per variable
- Monthly and annual aggregations
- Pearson correlation matrix across climate variables

### 3.3 Trend Analysis
- **Linear Regression:** y = mx + c for long-term temperature and precipitation trends
- **Warming Rate:** Calculated in °C per decade
- **STL Decomposition:** Seasonal-Trend decomposition using Loess (365-day period)

### 3.4 Anomaly Detection
- **Z-Score Method:** |Z| > 2.5 threshold for univariate anomaly detection
- **Isolation Forest:** Unsupervised ML with contamination parameter 0.05
- **Combined Flag:** Union of both methods for robust detection

### 3.5 Time-Series Forecasting
- **Algorithm:** Holt-Winters Exponential Smoothing (Triple)
- **Seasonal Period:** 365 days (annual cycle)
- **Horizon:** 3-year projections
- **Confidence:** 95% prediction intervals

## 4. Climate Risk Score

### Formula
```
Risk Score = (0.40 × Temp Trend Metric) + (0.30 × Rainfall Deviation Metric) + (0.30 × Anomaly Frequency Metric)
```

### Categories
| Score Range | Category  |
|-------------|-----------|
| 0.00 - 0.25 | Low       |
| 0.25 - 0.50 | Moderate  |
| 0.50 - 0.75 | High      |
| 0.75 - 1.00 | Very High |
